# 国税徴収法 Knowledge Lab — 2027年受験向け

**目的:** 国税徴収法の「理解 → 暗記 → 記述演習 → 過去問 → 間違いを再復習」を一つにつなぐ個人用Webアプリ。iPhone・iPad・PCに対応したレスポンシブデザインです。

## はじめに

このアプリは**学習機能が動く初期版**です。購入した理論テキスト全文や本試験問題本文・公式模範解答を同梱した完成教材ではありません。学習用の92論点チェックリスト、11件の独自要約理論カード、6件のオリジナル記述問題を初期登録しています。未登録の理論・問題は教材の写真やJSONを使って増やせます。

## できること

- 10分野・92論点の学習チェックリスト（公式の全論点網羅を保証するものではありません）
- 理論カードの追加・編集、趣旨、条文、理解のポイント、短い解答、キーワード、関連問題、出典管理
- 理論の自己テスト、解答の表示、キーワード穴埋め表示
- 自己評価に応じた復習日の設定。忘れた／曖昧→原則翌日、覚えた→1・3・7・14・30日…、簡単→3・7・14・30日…
- 今日の復習・苦手集中モード、8日間の復習予定、直近7日間の復習記録、分野別進捗
- オリジナル問題と過去問問題の分離、記述答案入力、キーワードの文字列照合と本人による自己評価
- 間違えた記述問題に関連付けた理論を再び復習対象にする仕組み
- 2026〜2019年度の公式過去問ページへのリンク。年度専用ページは2026・2025・2024年度を確認済み
- 年度別120分本試験タイマーと演習記録（画面を閉じるとタイマーは失われます）
- 写真の複数アップロード・圧縮・保存。理論と過去問／演習への画像の紐付け、拡大表示
- 任意のオンライン日本語OCR。ただし認識結果は未検証の文字起こしメモとして保存し、原本照合が必要
- ChatGPTからの`{"topics":[...],"questions":[...]}` JSON一括インポート
- 画像・理論・記述答案・復習履歴を含むJSONバックアップと復元
- HTTPSサイトに置くとホーム画面への追加・基本画面のオフライン利用に対応

## iPhoneで使う — GitHub Pages（無料）

1. このZIPを展開します。中の `kokucho-lab` フォルダに、`index.html` などが入っています。
2. GitHubで新しいリポジトリ（例 `kokucho-knowledge-lab`）を作成します。**教材の写真や個人の答案はGitHubにアップロードしないでください**。
3. `kokucho-lab` のフォルダ**の中のファイルをすべて**リポジトリのルート（最上位）にアップロードします。`index.html`, `app.js`, `data.js`, `style.css`, `sw.js`, `manifest.webmanifest`, `app-icon.png`, `icon.svg` 等が同じ場所になるようにします。
4. GitHubの `Settings` → `Pages` → `Build and deployment` → `Deploy from a branch` → `main` / `(root)` → `Save` を選びます。利用するリポジトリの公開設定・プランにより使える公開方法は変わる場合があります。
5. 表示された公開URLをiPhoneのSafariで開き、共有 → `ホーム画面に追加` を選びます。
6. **普段はホーム画面に追加した側だけで学習**してください。Safariタブとホーム画面版でブラウザ内データが別になる場合があります。

`file://` やiPhone「ファイル」プレビューでHTMLを直接開く方法は、ブラウザによってIndexedDBなどが制限されるため、保存用として推奨しません。

## 最初の勉強方法

1. 理論ライブラリで「差押えの要件」などのカードを開いて説明を確認します。
2. 「画像教材」で所有するテキストを撮影・追加して論点と紐付けます。画像はオンライン上のGitHubにアップロード**されません**。
3. 画像をChatGPTに渡し「作成用プロンプト」を使ってJSONを生成し、「データ・設定」のJSON欄に貼り付けます。必ず教材と照合してから暗記してください。
4. 通勤時間に「今日の復習」を実施し、自力で答えてから自己採点。解答の重要語句は「穴埋め」にできます。
5. 机で過去問の公式PDFを開き、登録済みの問題や自作問題で記述答案を練習します。間違えた関連理論を復習します。
6. 学習のたびに「データ・設定」→「画像も含む全データを保存」からJSONバックアップを出力し、**実際にiPhoneのファイルアプリやiCloud Driveに保存されたことを確認**してください。別端末への移行はJSON復元を使います。

## 重要な注意事項

- このアプリはChatGPT APIキーや有料サービスなしで基本機能が使えます。ただし外部OCRの日本語言語データ取得には通信が必要です。
- AIで画像を読み取る機能は**ChatGPTとの手動連携**です。Webアプリに画像をアップロードするだけでは自動的に正解や解説を生成しません。
- 法令・条文番号・2027年度の適用法令・改正対応は必ず最新版教材・法令で確認してください。初期カードは独自の短い要約で、完全な合格答案ではありません。
- 過去問の公式ページ・出題のポイントへのリンクを収録していますが、過去問全文・公式模範解答はアプリに入れていません。画像・問題文・答えの登録はユーザーが行います。
- キーワード一致は**AI採点ではなく**、論理の誤り・言い換え・否定・要件充足を判定しません。自己採点は公式採点基準と異なります。
- ブラウザのIndexedDBに保存し、**クラウド自動同期・ログイン機能はありません**。Safariのサイトデータ削除、ストレージ制限、機種変更、ブラウザごとの別領域には注意し、こまめにJSONバックアップを保存してください。
- GitHub Pagesに置くのはアプリの**コードのみ**。利用時に追加したテキスト画像・解答データはブラウザ内に保存します。著作権のある教材画像の公開や再配布は避けてください。

## システム構成

バックエンドなしの静的HTML + CSS + JavaScript、IndexedDB、Service Worker（PWA）。GitHub Pages等のHTTPS配信で利用可能。アプリの基本機能に外部アカウントは不要です。

## 動作確認

ブラウザ画面の表示、理論一覧、暗記・穴埋め、記述演習、20分タイマー、理論の追加、画像の登録はヘッドレスChromium（PC／iPhone相当の画面幅）で操作テスト済みです。ただしテスト時は保存処理をメモリに置き換えたため、GitHub Pagesや実際のiPhoneのSafariでの動作・自動同期までは保証しません。
